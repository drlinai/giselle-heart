# Giselle's Heart: Eternal Reunion 吉賽兒之心：永恆重逢

送給 Giselle 的生日禮物（2026.11.25）— 一款致敬惡魔城風格的 2D 橫向捲軸動作遊戲。

## 怎麼玩
- 直接雙擊 `GisellesHeart.html`（單一檔案、離線可玩）即可開始。
- 或用 `index.html`（模組化版本，程式碼在 `js/`）。
- 建議用 Chrome / Edge / Safari 開啟，全螢幕體驗最佳。

## 操作
| 按鍵 | 功能 |
|---|---|
| ← → | 移動 |
| 空白鍵 | 跳躍（空中再按一次 = 二段跳） |
| ↓ + 空白鍵 | 從單向平台往下跳 |
| A | 心形飛彈（遠距離攻擊，射程約半個畫面） |
| S | 瞬移衝刺（短暫無敵、可穿過敵人與子彈） |
| D | 心之波（能量條集滿後釋放，全畫面大傷害） |
| Enter / 空白鍵 | 對話下一句、確認 |

## 流程
1. 開場：Giselle 醒來發現家人消失，桌上留有紙條。
2. 地圖：選擇目的地，Giselle 走出並發動瞬間移動。
3. 第一關 台灣（台北 101）→ Boss「101 鋼鐵守護者」→ 救出 Rex（2 歲）
4. 第二關 新加坡（魚尾獅、金沙）→ Boss「石化魚尾獅」→ 救出 Liam（6 歲）
5. 第三關 月球（低重力）→ Boss「月之暗面・影王」→ 救出 William（38 歲）
6. 全家團聚、晚餐、洗澡、睡覺……隔天早上，換 William 醒來——全劇終（伏筆）。
7. 生日卡片。

生命無限，死亡會從最近的檢查點（愛心旗）重來。
